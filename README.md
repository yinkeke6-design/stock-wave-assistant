# A股波段助手 0.2

本版先按板块涨幅筛选最多12个行业/概念板块，再读取每个板块最多35只成分股的日线，识别箱体整理、接近箱顶、放量突破和突破回踩。分为即将突破观察、刚刚放量突破、突破回踩确认。行情日期取入选股票实际K线日期。

**限制：**目前尚未自动抓取政策新闻/公司公告并映射受益板块；只扫描强势板块的部分成分股，不是全市场全量扫描。东方财富公开接口可能限流或调整。筛选仅供研究，不自动下单。
