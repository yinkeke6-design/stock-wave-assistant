# A股波段助手 0.3

本版增加国务院公开政策页面线索抓取：读取政策列表标题，按产业关键词提示可能关联的行业，并提供原文入口。政策标题关键词匹配只是线索，不代表官方认定，也不构成受益公司结论。

技术筛选仍保留箱体整理、接近箱顶、放量突破和突破回踩识别。当前仍未完成政策原文深度分析、政策受益公司映射及全市场全量扫描；股票筛选范围和行情接口限制见页面说明。

**部署：**Cloudflare Pages 项目根目录为本目录，Framework preset None，Build command 留空，Build output directory `.`。提交后 Pages 通常自动部署。此版本只改 Pages Functions 和前端文件，不涉及 Worker。
